# News Paper Stall (NPS)

A tabloid-style daily news front page built with Next.js — loud headlines and dense coverage across politics, business, technology, sports, culture and opinion.

## Development

```bash
npm install
npm run dev
```

## Brand assets

`public/logo.svg` is the 512px brand mark and `public/favicon.svg` is the simplified
small-size mark. Regenerate `logo.png` and `favicon.ico` from those sources:

```bash
npm run logo
```
